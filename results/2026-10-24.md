## How to reproduce the Mnemosyne row

```bash
pip install mnemosyne-os
python -m harness.run --systems mnemosyne --datasets longmemeval,locomo,beam_1m,beam_10m
```

The harness writes `results/<run>.json` (machine-readable) and
`results/<run>.md` (the table). Diff two runs directly.

## What is a "run"

A run is: one `systems/` adapter + one `datasets/` questions.jsonl + the
scorer in `harness/scorer.py`. No other code participates. That is what
makes a published number verifiable by a stranger.
